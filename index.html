About

Periodic Table Lab is a study tool for chemistry students. Browse all 118 elements, open a tile for details, and hear a note for each one.

Use the search box and the category or block buttons to focus on part of the table. The calculator handles arithmetic and trigonometry in degrees or radians. The solution tool computes molarity and % m/v and works out how much solute to weigh. The quiz tests symbols, names and atomic numbers.

Electron configurations follow the Madelung filling order with the usual experimental exceptions. Atomic masses are rounded standard values; for the heaviest synthetic elements the mass number of the longest-lived isotope is shown. Elements 109 to 118 have few measured properties, so their category is predicted.

Keyboard: press Esc to close a panel, and use the arrow keys to move between elements while it is open.
